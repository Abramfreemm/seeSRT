# seeSRT 产品需求文档（PRD）

## 1. 项目概述

- **项目名**：seeSRT（字幕智能纠错工具）
- **一句话定位**：以剧本为「标准答案」，自动对齐并纠错达芬奇（DaVinci Resolve）语音识别导出的 SRT 字幕，检查台词完整度，支持批量处理。
- **背景与问题**：达芬奇内置语音识别导出的 SRT 常出现大小写错误、拼写错误、漏词等问题；剪辑师通常需要逐条对照剧本手动修改，耗时长且容易漏改。本项目把「剧本台词」作为唯一正确来源，自动完成对齐与纠错。

## 2. 目标用户与场景

- **目标用户**：影视后期剪辑师、字幕组、翻译/校对人员。
- **典型使用流程**：
  1. 用户拿到一份剧本（中英对照，一行中文、一行英文交替）。
  2. 上传剧本 → 系统自动提取「台词库」（中英对照的台词对）。
  3. 导入达芬奇导出的 SRT 文件 → 系统自动把字幕片段对齐到台词。
  4. 系统以剧本为准，修正字幕中的大小写、拼写、漏词等错误。
  5. 用户查看「完整度报告」（哪些台词缺失、哪些片段低置信度），可人工复核。
  6. 导出修正后的 SRT；支持批量处理多个文件。

## 3. 关键格式约定（重要）

- **剧本**：一个文件含全部集；内部用「集标题」（如「第一集」）+「场景编号」（如 `1-1`）分隔；台词为**一行中文、一行英文**交替；夹杂角色名、舞台提示、镜头说明等非台词内容。
- **字幕**：达芬奇识别的英文（或中英）SRT，标准 SRT 格式（序号 / 时间轴 / 文本）。

**字幕输出规范（拆分规则，达芬奇「23 字符」预设）**：
1. 只保留英文台词，去角色名/中文/舞台提示。
2. 标点全部英文半角（句号 `.` 逗号 `,` 省略号 `...` 叹号 `!`），每个占 1 字符。
3. 按语义和标点断句，每行一个完整意群。
4. 每行 ≤ 23 字符（英文半角，含空格 + 标点）。
5. 超长在逗号/连接词/介词短语/从句边界换行。
6. 不增删改词，只做换行。
7. 每片段最多 2 行（即 ≤ 46 字符）。
8. 超过 2 行拆新片段，时间轴按字符占比分配。
9. 处理流水线：先纠错 → 再拆分。

## 4. 功能需求

### 4.1 功能清单（按优先级）

| 优先级 | 编号 | 功能 | 说明 |
| --- | --- | --- | --- |
| P0 | F1 | 剧本导入 | 支持 `.docx` / `.txt` / `.fountain` |
| P0 | F2 | 台词提取 | 从剧本识别「集→场景→台词对」，过滤角色名/舞台提示 |
| P0 | F3 | 台词库可视化 + 编辑 | 展示识别出的台词，允许人工修正 |
| P0 | F4 | SRT 导入 | 解析 SRT 为结构化片段（序号/时间轴/文本） |
| P0 | F5 | 台词↔字幕对齐 | 将 SRT 片段匹配到台词 |
| P0 | F6 | 自动纠错 | 以剧本为准修正大小写/拼写/漏词，保留时间轴 |
| P0 | F7 | 导出修正 SRT | 无损导出标准 SRT，每片段最多 2 行 |
| P0 | F8 | 差异高亮视图 | 修改处红色标亮，逐条 diff 对比 |
| P1 | F9 | 完整度检查报告 | 缺失台词 / 多余片段 / 低置信度告警 |
| P1 | F10 | 批量处理 | 多集并行（每集一个 SRT）、自动定位集数 |
| P2 | F11 | 置信度打分 + 复核队列 | 低置信度片段进入人工复核队列 |

### 4.2 功能详细说明

**F2 台词提取**
- 输入：剧本文档；输出：`[{集, 场景, 中文台词, 英文台词}]` 列表（集 → 场景 → 台词对）。
- 识别「集标题」（如「第一集」）和「场景编号标题」（如 `1-1`），台词归入对应集 + 场景。
- 规则优先：利用「一行中文、一行英文」的交替结构按行配对，过滤角色名/舞台提示。
- LLM 兜底：处理不规则排版（多行对白、缺行、混排、集/场景标题识别）。

**F5 对齐**
- 输入：台词库 + SRT 片段列表；输出：每个 SRT 片段的命中台词或「未命中」标记。
- 需处理：一句台词被拆成多个 SRT 片段、片段拼接、顺序漂移。

**F6 纠错**
- 命中台词时，以剧本原文覆盖字幕文本（时间轴保留），修正大小写/拼写/漏词；**大小写以剧本为准**（剧本即标准答案，句首大写、专有名词/I/缩略词天然正确）。
- 未命中片段标记为「需人工复核」，**不**由 LLM 生成替换文本（避免幻觉），也不自动改大小写。

**F8 差异高亮视图**
- 每个片段保留「原始文本」与「修正后文本」，用 `difflib` 逐词 diff 计算差异。
- UI 中修改/新增的文本用**红色**标亮，删除的文本用红色删除线；逐条展示「原始 → 修改后」。

**F10 批量处理**
- **多集并行**：一部剧多集，每集一个剧本文件 + 一个 SRT 文件（文件名 = 集数）。可批量导入多集，多集并行处理、互不干扰。
- **自动定位集数**：SRT 文件名即集数（如 `1.srt`、`01.srt`）直接解析；无法解析时用内容相似度兜底匹配到对应集的剧本。

## 5. 核心业务流程

```
剧本文件 ──► [台词提取] ──► 台词库（集→场景→台词）

SRT文件 ──► [SRT解析] ──► 字幕片段列表
                              │
                              ▼
                        [对齐引擎]
                              │
                              ▼
                        [纠错引擎] ──► 修正后的 SRT
                              │
                              ▼
                        [完整度报告]
```

### 5.1 批量处理流程

```
项目/剧 ──► 多个剧本文件（每文件 = 一集）
                │
        ┌───────┴────────┐
        ▼                ▼
     第01集            第02集 ...
  (1.srt 导入)       (2.srt 导入)
        │                │
   自动定位集数        自动定位集数
        │                │
   每集独立纠错        每集独立纠错
        │                │
  修正 1.srt        修正 2.srt
（各集任务可并行执行）
```

## 6. 非功能需求

- **本地运行**：剧本与字幕数据不出本机，保护版权与隐私。
- **端口**：Web UI 固定使用 **8877**。
- **纠错零幻觉**：以剧本为标准答案，纠错逻辑不依赖 LLM 生成文本。
- **中英混合支持**：对齐与纠错同时兼容中文与英文。
- **性能**：单集字幕（数百至数千条）处理应在秒级完成（不含模型推理时间）。

## 7. 验收标准

- 上传一份中英对照剧本 + 一份含错误的 SRT，可在数分钟内导出修正后的 SRT。
- 命中台词的大小写/拼写错误 100% 被修正。
- 完整度报告能列出所有缺失台词与多余片段。
